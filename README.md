# 🤖 React Chatbot

A simple chatbot application built with **React** that allows users to send messages and receive AI-generated responses. The project demonstrates core React concepts such as components, state, props, hooks, conditional rendering, controlled inputs, and list rendering.

## 📸 Preview

[<img src="robot.png" alt="Chatbot Preview" width="150">](https://emperorfrost17-png.github.io/React-ChatBot/)

---

## ✨ Features

- 💬 Send and receive chat messages
- ⚛️ Built entirely with React Components
- 📝 Controlled input field
- ⌨️ Keyboard shortcuts
  - **Enter** → Send message
  - **Escape** → Clear input
- 🔄 Auto-scrolls to the newest message
- ⏳ Loading animation while waiting for a response
- 👤 Separate message layouts for the user and chatbot
- 📱 Clean and responsive layout

## ⚙️ How It Works

1. The user types a message.
2. Press **Enter** or click **Send**.
3. The message is added to the chat.
4. A loading animation is displayed.
5. The chatbot generates a response.
6. The response appears in the conversation.
7. The chat automatically scrolls to the latest message.
